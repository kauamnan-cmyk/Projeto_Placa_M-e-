Sobre o Projeto

Este site educacional foi desenvolvido para apresentar de forma clara, didática e estruturada os conceitos fundamentais da Arquitetura de Computadores. Tomando como base a placa-mãe ASUS TUF Gaming A520M-PLUS, o projeto detalha o papel de cada circuito e peça na comunicação do hardware.

O objetivo é desmistificar o funcionamento interno dos computadores, mostrando como a CPU, a Memória RAM, as memórias secundárias, as interfaces de E/S (como USB) e as vias de expansão (como o barramento PCI Express) interagem em harmonia para executar tarefas e programas do cotidiano.

Projeto acadêmico construído com tecnologias web modernas (HTML5, CSS3, JavaScript), fornecendo diagramas interativos, dados técnicos estruturados e recursos visuais premium.
